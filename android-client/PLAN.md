# ClaudeLink Android 全面升级计划

## 问题分析

### 1. 终端乱码问题 🔴
**根本原因**：
- AnsiParser.kt 的正则表达式缺少 ESC 字符 (`\x1B`)
- 正则: `\[([0-9;]*)m` 应该是 `\x1B\[([0-9;]*)m`
- 导致 ANSI 转义序列没有被正确识别和解析
- 控制字符直接显示在终端上

**对比 Web 端**：
- Web 端使用 xterm.js，完整支持 ANSI/VT100
- 正确处理所有转义序列

### 2. UI 设计问题 🎨
**当前问题**：
- 颜色单调（只有深蓝色）
- 按钮样式过于简单
- 缺乏视觉层次
- 没有现代感
