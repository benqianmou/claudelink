# Project Details (项目技术细节)
- Windows 宿主端：基于 Node.js，必须使用 `node-pty` 库来派生（spawn）Claude 进程，以此捕获 ANSI 转义序列、色彩字符并处理标准输入输出流。
- 网络通信层：采用双向 WebSocket 协议，将 Windows PTY 的原始流数据实时推送到手机。
- Android 移动端：采用 Android 原生开发（Kotlin），连接 WebSocket 接收流数据，解析 ANSI 编码并渲染成终端界面。
