# ClaudeLink

Remote-control Claude Code on a Windows host: a Node.js PTY + WebSocket server with a web UI (`windows-host/`) and a native Android client (`android-client/`).

## Agent skills

### Issue tracker

Issues live as GitHub issues on `benqianmou/claudelink`, driven with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map 1:1 onto this repo's labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
